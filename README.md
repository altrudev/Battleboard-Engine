# Battleboard Engine

Battleboard Engine is the reusable runtime foundation for Battleboard, based on a pinned Godot 4.7.1-stable foundation.

v0.3 contains deterministic board state and movement rules, fighter profiles, affinity/resonance evaluation, procedural fighter presentation, and a deterministic tactical planner used by opponent boards.

The game-specific campaign, recruitment, training, tournament progression and content remain in Battleboard-Game.
